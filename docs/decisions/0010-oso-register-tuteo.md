## Decision

Colombian Spanish addresses the operator with tuteo (tú), switching to usted only where it is the natural idiom (for example "hágale pues"). Voseo is banned: no vos, sabés, tenés, querés, podés.

## Context

The ban is explicit because voseo is the failure mode a generic Latin-American Spanish drifts into.
