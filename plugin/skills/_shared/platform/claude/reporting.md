# Milestone reporting — Claude Code

## The native card is not the report

Launching a delegation through the Agent tool, or forking a judge through the Skill tool, draws this client's own native subagent card — a UI element the harness does not control and cannot suppress. That card shows only THAT something ran; it carries no role name the operator recognizes, no assignment, no tree, and no verdict. The milestone text `../../reporting.md` requires is never skipped because a card is already on screen, and it is never folded into the card's own caption — it is separate operator-facing content, delivered exactly as every other one on this host: ending the turn as plain text, with the tool call in a later turn.
